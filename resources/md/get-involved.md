Jolt is developed in the open, and there are many ways to get involved.

## Join the conversation

The easiest way to participate in development is the **#jolt** channel on [Clojurians Slack](https://clojurians.net) — that's where all the discussion happens. Sign up at [clojurians.net](https://clojurians.net), join **#jolt**, and say hello.

It's the place to ask questions, share what you're building, get help with anything that isn't working, and follow — or weigh in on — design decisions as they happen.

## Report bugs and request features

If something doesn't behave the way you expect, or you have an idea for an improvement, open an issue in the [jolt-lang/jolt](https://github.com/jolt-lang/jolt/issues) tracker. Steps to reproduce and the error output go a long way.

## Contribute code

Pull requests are welcome. The [Module Map](/docs/MODULES.html) is a contributor-oriented tour of the codebase, and the [RFCs](/docs/rfc/README.html) describe ongoing design work — pick something that interests you, and ask in **#jolt** if you're unsure where to start.

## Improve the documentation

The source for this site lives in the [jolt-lang/jolt-lang.github.io](https://github.com/jolt-lang/jolt-lang.github.io) repository. To update a page, edit the Markdown file under `resources/md`; to add one, create the file and register it in `resources/docpages.edn`.
